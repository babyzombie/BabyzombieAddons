# BabyzombieAddons

Hypixel SkyBlock 生活质量工具模组，[Fabric](https://fabricmc.net/) 客户端模组。

> QQ 交流群：1097087618
>
> 本项目的开发过程主要以 AI 辅助制作完成（需求分析、代码实现、审查与迭代）。

[GitHub](https://github.com/babyzombie/BabyzombieAddons) · [Gitee](https://gitee.com/Bluesky-kk/BabyzombieAddons)

## 项目概览

- **定位**：面向 Hypixel SkyBlock 的客户端侧 QoL/提示/自动化辅助模组，覆盖地牢、Kuudra、Slayer、挖矿、钓鱼、花园、队伍与聊天、活动等玩法域。
- **核心能力**：提供 HUD 展示、路径点/信标/光柱标记、聊天与交互增强、战斗/技能/道具计时、关键节点提示与保护，以及大量可配置开关与搜索标签。
- **适用场景**：日常跑图与刷任务、地牢/Kuudra 车队配合、Slayer/猎手打 Boss、Crystal Hollows/Glacite 挖矿路线、钓鱼稀有海怪提醒、花园害虫/温室/告示牌等农场操作优化。

## 快速上手

- 🧩 **安装依赖**：按下方“安装”部分完成前置安装与启动。
- ⚙️ **打开设置**：进入游戏后输入 `/bza` 打开设置界面，根据玩法分类启用需要的功能。
- 🧭 **HUD 与显示类功能**：在 HUD 编辑器中拖拽/调整位置，按需求开关显示、颜色与透明度等。
- 🔎 **快速定位选项**：多数功能都支持搜索标签与分类筛选，适合快速查找开关。

## 主要功能

- **通用 / 杂项**：检查更新、HUD 编辑器、断线自动重连与恢复、窗口标题、自定义铃声/来电提示、玩家视角与交互 QoL 等
- **聊天 / 队伍**：响应聊天指令与自动化（`!allinv / !p / !warp / !join / !sc / !play / !pt`）、频道识别、交互式弹窗通知（组队/好友/交易等）
- **地牢（Dungeon）**：自动重开、F4 观众隐藏、Storm 雷声静音、每日场次计数、关箱子/稀有掉落声音处理、Wither Cloak HUD/计时等
- **Kuudra**：血量与阶段信息、阶段/眩晕计时器、路径点与信标、弩炮/补给进度 HUD、补给与箭毒/珍珠补充提醒、商店与界面保护等
- **Slayer**：Boss 探测与边框/HUD、低血量警告、Boss 重生提示、多类道具/护甲/技能计时器
- **挖矿（Mining）**：Crystal Hollows/Glacite 相关路线与传送辅助、晶核自动传送、钻头挥动抑制、矿井路径点与计数器、挖粉音效与冷却辅助等
- **钓鱼（Fishing）**：稀有海怪扫描与高亮（光柱/Title，可配置扫描半径、排除列表、Title 重复策略）、防止抛竿后瞬间收杆等
- **花园（Garden）**：害虫标记、温室检测与保护、Trevor 自动接取/呼叫、告示牌自动转向、经验球与音效优化等
- **猎手（Hunting）**：Safari/Torrhus Canyon 等玩法域提示与显示（例如实体高亮、记录与辅助信息）
- **活动（Events）**：Great Spook 助手、挖水果助手、Raffle 任务等
- **小游戏（Minigames）**：Ravengard 等小游戏域辅助

## 核心功能详解

下面以“怎么用 → 适用场景 → 实际效果”为主线，帮助你快速掌握各核心能力（不涉及任何底层技术细节）。

### 🧰 通用 / 杂项（全局 QoL）

- ✅ **怎么用**：打开 `/bza` → 在“通用/杂项”分类中按需启用 → 若涉及 HUD，在 HUD 编辑器中调整位置与样式。
- 🧭 **适用场景**：日常跑图、长时间挂机/刷本、频繁切场景/切岛、需要减少无效操作与干扰信息时。
- ⭐ **核心优势**：把“高频、重复、容易忘”的小细节做成可控开关，让你更专注于玩法本身。
- 👀 **实际效果**：减少误操作与信息噪音，界面更清爽，关键提示更集中。

### 💬 聊天 / 队伍（沟通与协作效率）

- ✅ **怎么用**：打开 `/bza` → 启用聊天/队伍相关开关 → 在队伍聊天中直接使用 `!warp/!join/!p/...` 等指令交互（无需切到命令输入的思路）。
- 🧩 **适用场景**：组队刷本、车队集合、需要快速拉人/传送/同步信息时。
- ⭐ **核心优势**：减少切输入框与重复输入，让队伍指挥更顺滑；同时提供更直观的交互弹窗，降低错过邀请/请求的概率。
- 🎯 **实际效果**：队伍响应更快、沟通更少打断，整体节奏更连贯。

### 🏰 地牢（Dungeon）（节奏与提醒）

- ✅ **怎么用**：进入地牢前在 `/bza` 中提前开启对应功能 → 进本后按提示/计数进行配合 → 需要 HUD 的功能在 HUD 编辑器中摆放到合适位置。
- 🧭 **适用场景**：日常刷层、速通、队伍协作要求高的场景，或对声音/视觉干扰比较敏感的玩家。
- ⭐ **核心优势**：把“关键节点”和“易忽略细节”用更明确的方式呈现出来，减少漏看、漏做与走神成本。
- 🔔 **实际效果**：更少的重复沟通与纠错，队伍节奏更稳定，效率更高。

### 🔥 Kuudra（阶段信息与战斗辅助）

- ✅ **怎么用**：开局前在 `/bza` 中启用 Kuudra 相关功能 → 将阶段/眩晕计时、进度类 HUD 放到视线易扫的位置 → 按提示完成补给、弩炮等流程配合。
- 🧭 **适用场景**：Kuudra 多阶段推进、需要频繁查看进度与资源状态的战斗流程。
- ⭐ **核心优势**：信息更集中、关键进度更直观，减少“看不到/看不清/反应慢”的问题。
- 🧠 **实际效果**：队伍分工更清晰，推进更顺，容错率更高。

### ⚔️ Slayer（Boss 探测 + 计时体系）

- ✅ **怎么用**：在 `/bza` 的 Slayer 分类中启用 Boss 信息/HUD/提示 → 对常用装备与技能计时器按需开启（只开自己用得到的）→ 通过 HUD 或提示把握窗口期。
- 🧭 **适用场景**：刷 Slayer、控技能循环、需要把握爆发/保命时机的战斗。
- ⭐ **核心优势**：把“靠感觉”的计时变成“可视化的节奏”，降低误判与空转。
- 💥 **实际效果**：技能衔接更稳定、输出/生存更可控，刷本更轻松。

### ⛏️ 挖矿（Mining）（路线与效率）

- ✅ **怎么用**：在 `/bza` 的挖矿分类中按地图/玩法选择开启（Crystal Hollows / Glacite 等）→ 把需要的路径点/计数器/HUD 打开 → 按提示进行传送与路线规划。
- 🧭 **适用场景**：跑图挖粉、找路线、计数统计、减少无效挥动与误操作的挖矿流程。
- ⭐ **核心优势**：让路线与状态信息更“可见”，减少迷路、重复走、漏信息造成的时间浪费。
- 📈 **实际效果**：移动更顺、效率更稳，长时间挖矿更省心。

### 🎣 钓鱼（Fishing）（稀有海怪与操作保护）

- ✅ **怎么用**：`/bza` → Fishing → 开启“稀有海怪高亮”相关选项 → 按习惯设置：
  - 🔎 **扫描半径**：1–25 可调，范围越大提示越积极；
  - 🚫 **排除海怪高亮列表**：勾选想忽略的海怪（启用“排除指定海怪高亮”后生效）；
  - 🔁 **重复提示海怪 Title**：开启后会按冷却重复提示；关闭则每只实体只提示一次。
- 🧭 **适用场景**：热点钓鱼、活动钓鱼、需要快速判断“是否值得处理”的稀有海怪出现时刻。
- ⭐ **核心优势**：把稀有目标从杂乱信息中“拉出来”，并支持按个人策略过滤；提示更可控，不吵也不漏。
- ✨ **实际效果**：更快发现稀有海怪、更少错过窗口期，且对不想处理的目标可以一键屏蔽。

### 🌿 花园（Garden）（农场操作与提示）

- ✅ **怎么用**：`/bza` → Garden → 按需开启害虫/温室/告示牌等辅助 → 需要显示类功能时在 HUD 编辑器中调好位置。
- 🧭 **适用场景**：刷害虫、温室相关操作、Trevor 任务、日常种植维护。
- ⭐ **核心优势**：减少“手忙脚乱”的微操作，把注意力从找目标/找按钮转回到流程本身。
- 🌱 **实际效果**：操作更顺、走位更少绕路，任务推进更连贯。

### 🐾 猎手（Hunting）（目标与信息可见性）

- ✅ **怎么用**：`/bza` → Hunting → 按玩法域开启提示/显示类功能 → 配合自身路线/任务节奏使用。
- 🧭 **适用场景**：Safari、Torrhus Canyon 等需要找目标、盯信息、控制节奏的玩法。
- ⭐ **核心优势**：提高目标可见性与信息密度，让“找”和“等”的成本更低。
- 🎯 **实际效果**：更少漏目标、更少走冤枉路，整体体验更顺畅。

### 🎉 活动（Events）与 🎮 小游戏（Minigames）

- ✅ **怎么用**：活动/小游戏开始前在 `/bza` 对应分类提前打开 → 进玩法后按提示与辅助信息完成流程。
- 🧭 **适用场景**：限时活动、需要快速上手或流程复杂的小游戏/活动内容。
- ⭐ **核心优势**：降低学习成本与流程出错率，让你把精力放在收益与节奏上。
- 🥇 **实际效果**：更快进入状态、减少卡流程、活动体验更稳定。
